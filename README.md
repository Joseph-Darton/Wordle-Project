# Wordle-Project
Python project that uses web scraping and The Natural Language Toolkit (NLTK) library to determine a list of valid five letter words using the most common letters found in past wordle solutions. These words were then analysed for audience familiarity using Datayze.com to determine how well known/difficult they are. The script outputs three excel files:
<br>
- list of previous wordle solutions
<br>
- the top 10 most common letters and the number of times they have appeared in previous solutions
<br>
- list of valid five letter words using the top 10 most common letters and their readability

NLTK package used: https://www.nltk.org/api/nltk.corpus.html
<br>
Word Analyser: https://datayze.com/word-analyze
<br>
Past wordle solutions: https://stuckonwordle.com/all-wordle-answers.html
<br>
